Everything Agents Need to Run Safely

🛡

Risk Classification

Built-in rules engine auto-classifies actions as LOW/MEDIUM/HIGH/CRITICAL. Destructive SQL, bulk operations, and file deletions are caught before execution.

💰

Budget Control & Forecasting

Per-action cost tracking, budget limits, burn-rate analysis, and exhaustion prediction. Know exactly when your budget will run out.

⏪

Instant Rollback

Deep-copy state snapshots let you undo any action with a single call. Auto-snapshot on every tool execution.

⚡

Circuit Breaker

Auto-disable tools that fail repeatedly. CLOSED/OPEN/HALF_OPEN states with configurable thresholds and recovery probes.

👤

Human-in-the-Loop

Approval workflows with configurable timeout, auto-deny, callback-based approval, and escalation chains for high-risk actions.

🔒

Agent Capabilities

Fine-grained allowlist/denylist per agent. Argument constraints, cost limits, and time-based access schedules.

🔍

Distributed Tracing

OpenTelemetry-compatible spans for every action. Nested spans, JSON/OTLP export, trace grouping.

💥

Chaos Engineering

Fault injection (errors, latency, timeouts, corruption) with probability control, conditional triggers, and wildcard rules.

📊

Agent Scoring

Safety/reliability/efficiency/risk scoring (0-100) with A-F grades. Multi-agent pool rankings and leaderboards.

📜

Compliance Reports

SOC2/GDPR-ready audit reports from SQLite logs. Anomaly detection, risk breakdown, JSON/HTML export.

🚦

Rate Limiting

Sliding-window counters: global RPM/RPH and per-tool limits. Auto-prune for memory efficiency.

🛠

5 Framework Integrations

OpenAI, Anthropic Claude, LangChain, CrewAI, Microsoft AutoGen. Zero import overhead — frameworks are optional.
